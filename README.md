# 绿星图光｜农业产量图谱

面向农业生产与市场研究的气候—作物—产业信息平台。它将气候变化、作物敏感期、产量估计和市场信息组织为可追溯的研究上下文，帮助团队更高效地识别需要关注的区域和事件。

## 快速开始

```bash
pip install -e .
python -m agro.cli graph-stats
python -m agro.cli layouts
python -m agro.cli yield --layout rice.changjiang.single --warm-demo
python -m agro.cli ai-serve
```

更多命令、部署方式与研究资料见 `docs/`。

## 覆盖范围

- 中国三主粮：东北春玉米、黄淮海夏玉米、华北冬小麦、长江中下游一季稻、华南早稻
- 大豆：东北春大豆、美国大豆带、巴西马托格罗索
- 玉米：美国玉米带
- 棉花：新疆棉区、美国德州高原
- 咖啡：巴西米纳斯阿拉比卡、云南小粒咖啡

平台围绕蒸散、降水、花期与灌浆期、高温、低温和渍害等因素建立作物敏感性描述，并持续扩展区域与数据连接能力。

## 交付清单与门槛

平台不给一个总分，而是把贡献拆成互不相干的机制，各自单独检验，只交付通过检验的部分。

| 机制 | 检验方式 | 当前状态 |
| --- | --- | --- |
| 产量估计 | 逐年前向 + 选择偏差守卫（三道门槛） | 大豆/BRA、棉花/USA、玉米/USA 通过 |
| 风险结构 | 随机方向对照 | 通过，最大回撤由 −33.08% 收敛到 −2.31% |
| 注意力路由 | 大惊喜提升度 | 未通过（1.013），不作为功能 |
| 价格方向 | 随机符号零分布上尾 | 未通过（分位 0.3025），不列入任何交付清单 |

产量组的交付资格按年重算：任一组在新一年的前向测试里连续两次输给「照抄去年」即摘掉。
细节与完整表格见 [`docs/14-用户适配与交付门槛.md`](docs/14-用户适配与交付门槛.md)。

```bash
python -m agro.cli audience --table   # 交付清单与预期
python -m agro.cli trader --table     # 风险边界与账户口径
python -m agro.cli accuracy --table   # 逐路径精度
```

## 按使用者适配

同一份结果对不同使用者的价值不同，因此按目标函数分别交付：

- **初学者**：交易台结构——波动定仓、ATR 止损、时间止损、单笔风险上限。这项价值来自纪律而非预测，随机方向在同一结构下的回撤中位为 −2.04%，两句话一起说。
- **熟悉者**：通过门槛的三个作物-国家组的年度产量估计，用于替换「照抄去年」的基线。
- **尖端**：季内展望相对开局的偏离序列、原始因子与物候权重，接入对方自有的定价模型。

## 研究验证与应用边界

项目使用逐年前向切分、选择偏差守卫、市场事件研究、随机符号零分布和多链路复盘等方法评估稳健性。所有方向类结论都要求落在随机零分布 95% 上尾之外才会被采用，当前未达到，因此平台不提供交易方向。

气候、产量和市场信息需要联合研判；平台输出用于研究支持与风险关注，不构成交易、收益或经营承诺。

## 绿星 Agent 助手

绿星助手提供气候、产量、市场和研究验证的结构化解读，并支持来源提示、覆盖说明与不确定性表达。启动服务后，在 Web 界面点击左下角绿星按钮即可使用；未配置模型服务时，仍可使用本地结构化能力。

## 数据与更新

平台的数据连接和区域覆盖会按数据源可用性逐步升级。输出应结合来源、更新时间和当地实际情况使用，不能替代专业生产或投资判断。
