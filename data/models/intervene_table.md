# 信息干预框架与模拟决策

- 平均基线：当季第一条物候展望 = 开局基线。知情交易者开季已有产量预期，开局当天不干预
- 做多：factor ≤ 开局 − 0.03 → 季内恶化 → 减产预期 → 模拟做多
- 做空：factor ≥ 开局 + 0.03 → 季内好转 → 增产预期 → 模拟做空
- 不干预：相对开局落在带宽内则不干预、不持仓
- 事件：连续同一状态合并为一次干预，不是每个 3 日截面翻仓
- 不是自动交易系统；模拟决策只用来核对方向
