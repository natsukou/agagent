# 绿星图光 Web

这是绿星图光的浏览器界面，用于呈现农业气候、作物布局、策略情报、知识图谱和 AI 研究助手。

## 核心体验

- Dashboard：项目概览、图层与研究摘要
- 作物布局：重点产区、作物选择、产量预期与关键生育阶段
- 策略情报：市场观察、策略卡片与风险提示
- 图模型：可筛选、可展开的知识关系视图

地图与市场信息用于研究呈现和交互演示，需结合权威数据源及实际业务场景复核后使用。

## 本地运行

```bash
python -m agro.cli ai-serve
python -m http.server 8080 -d web
```

随后访问 `http://localhost:8080`。

## AI 助手

页面左下角的绿星助手可提供图谱、产量、市场和研究验证的结构化解读。服务端模型配置应通过安全的密钥管理方式提供，绝不应提交到仓库或暴露在浏览器中。未配置模型服务时，界面仍支持本地结构化交互。

## 设计原则

界面采用农业信息表达优先的视觉系统，强调可读性、信息层次与研究过程的可追溯性。接入新的地图或业务数据时，应保持数据来源、更新时间和适用边界的明确说明。
