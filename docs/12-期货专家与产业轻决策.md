# 期货专家与产业轻决策

旧规则把方向压成 `-sign(delta)`。截面一过阈值就翻仓，既没有价格形态，也没有把产业展望当成二次约束。`expert` 把它拆成两段，且两段都看不见建仓日及之后的行情。

## 两段分别做什么

**期货专家**只读信息日及之前的 K 线：1/3/5/10 日收益、10 日波动、20 日动量、均线偏离、量比。两层 MLP 输出 `tanh` 分数，`|score| ≥ 0.08` 才出手。训练只用主链、测试年之前的截面，按年切分，不打乱。

**产业轻决策**沿用 `intervene.py` 的口径：当季第一条展望是基线，偏离超过带宽才有方向。它不做第二个深度模型，只调整专家：

- 产业中性：保留专家
- 两者同向：保留专家
- 两者冲突：改 hold，不翻转
- 专家空仓：允许产业补位

冲突时空仓，是为了避免把两套弱信号叠成一套假强信号。

## 怎么验收

尺子与 `strategy` 相同：不重叠成交、标称双边成本、随机符号零分布上尾。报告对照三套方向：旧规则 / 专家单独 / 专家+产业。产出在 `data/models/expert_table.md`。

官方入口是策略体系本身：

```text
python -m agro.cli strategy --table --test-years 2023,2024
```

`expert` 仍可单独出对照表：

```text
python -m agro.cli expert --table --test-years 2023,2024
```

这不是当前交易建议。专家层只学价格形态，产业层只解释已建图的展望偏离。
