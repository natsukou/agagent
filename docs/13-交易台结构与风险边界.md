# 交易台结构与风险边界

`intervene` 给出「该不该介入、往哪个方向」。但一个方向信号不等于一笔交易。
`trader` 补上执行与风控这一层，让每一笔模拟决策都有明确的边界，
并给出一个真正的账户口径。

## 一、为什么必须有这一层

早期的 `personas` 把方向乘上整段价格涨跌再把各条链相加。
那个口径没有账户：数值可以跌破 −100%，高波动的品种会主导合计。
它能比较「谁的判断更好」，但不能回答「账户会变成什么样」。

`trader` 换成一个真实账户：所有链的成交按时间排入同一条净值曲线，
每笔只投入按波动算出来的仓位。同一批信号，累计从 −171% 变成 −1.43%，
最大回撤 −2.31%。差别全部来自风控结构，信号本身一个字没改。

## 二、结构（`TradeRules`，八条显式参数）

| 结构 | 取值 | 作用 |
| --- | --- | --- |
| 风险单位 | 每笔账户的 0.75% | 单次判断错误不影响后续能力 |
| 止损定位 | 2×ATR(14) | 止损由品种波动决定 |
| 头寸规模 | 名义敞口 = 风险预算 ÷ 止损距离，上限 1× 账户 | 高波动品种自动减仓 |
| 止盈 | 3×ATR，结构赔率 1.5R | 命中率低于一半也可能有正期望 |
| 保本移动 | 浮盈 +1R 后止损移到成本价 | 保护已实现的有利走势 |
| 时间止损 | 最多 15 个交易日，状态结束即离场 | 不无限期持有等基本面兑现 |
| 信念分档 | 偏离 ≥ 2×带宽给满档，否则半档 | 仓位与信号强度挂钩 |
| 账户口径 | 各链成交按时间复利 | 净值有下界 |

成交假设一律取不利侧：同一根 K 线同时触及止损与止盈按**止损**成交；
跳空穿越止损按**开盘价**成交，允许亏损超过 1R。
日内只有高低价，无法判定先后，所以只能这样取。

## 三、验收

```text
python -m agro.cli trader --table
```

产出 `data/models/trader_table.md`。2016–2024、四条主链、25 笔模拟成交：

- 命中率 36%，平均盈利 0.89R，平均亏损 −0.70R，实际赔率 1.27
- 离场构成：止损 10、状态结束/时间止损 9、保本离场 4、止盈 2
- 账户累计 −1.43%，最大回撤 −2.31%

三种交易者在这个口径下的对照：

| 角色 | 无干预 | 有干预 | 无干预最大回撤 | 有干预最大回撤 |
| --- | --- | --- | --- | --- |
| 初学者（每季死拿多头） | +6.50% | −1.43% | −33.08% | −2.31% |
| 熟悉者（沿用去年，空仓） | 0 | −1.43% | 0 | −2.31% |
| 尖端（按绝对胁迫进场） | −3.38% | −1.43% | −3.65% | −2.31% |

## 四、方向为什么不作为交付物

判定方向有没有信息，尺子仍是随机符号零分布，
但零分布必须跑**同一套** ATR 止损、同样的建仓日与头寸规模，
只把事件方向换成随机 ±1（2000 次）。
否则 1.5R 赔率结构本身带来的收益会被误读成方向能力。

| 全账户期望 R | 值 |
| --- | --- |
| 随机方向 5% 分位 | −0.3334 |
| 随机方向中位 | −0.0234 |
| 实际 | −0.1274 |
| 随机方向 95% 分位 | +0.2866 |
| 实际所处分位 | 0.3025 |

上尾不显著。因此 `trader` 的定位是**风险边界与口径**，不是方向来源。
方向层只作为解释材料，交付清单里没有它。
这条判定写进了 `audience`（见 `docs/14`），由门槛机制强制执行。

## 五、口径限制

- 连续主力序列含换月跳空，ATR 与止损都会被跳空污染
- 未建模保证金追缴、涨跌停无法离场、止损单被穿的滑点
- 25 笔成交远达不到统计可信规模，任何单链结论都不成立
- 初学者基线刻意保留无止损的原状，不代表推荐做法
- 全部为历史模拟，不是当前交易建议
